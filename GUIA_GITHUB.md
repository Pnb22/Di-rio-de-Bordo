# Guia de submissão no GitHub

## Passo 1: criar repositório
1. Entre no GitHub e clique em New repository.
2. Use o nome `Di-rio-de-Bordo`.
3. Mantenha o repositório público.

## Passo 2: configurar Git local
1. Abra o terminal.
2. Vá para a pasta do projeto.
3. Rode:
   - `git init`
   - `git add .`
   - `git commit -m "Otimização de Performance Web"`

## Passo 3: enviar para o GitHub
1. Copie a URL do repositório no GitHub.
2. Rode:
   - `git remote add origin <URL>`
   - `git branch -M main`
   - `git push -u origin main`

## Passo 4: confirmar
- Verifique se os arquivos estão no GitHub.
- Confirme se `README.md` aparece corretamente.
