# Leia primeiro

Este projeto é um PWA simples para anotações. As principais mudanças feitas foram focadas em melhorar a performance e o suporte offline.

## O que foi alterado
- Adicionei meta tags e manifest.
- Usei `defer` no JavaScript.
- Ajustei o CSS para evitar mudanças de layout.
- Melhorei o service worker.
- Criei o ícone 512x512.

## Por que foi feito
- Para o app carregar mais rápido.
- Para funcionar como PWA.
- Para melhorar o comportamento offline.
